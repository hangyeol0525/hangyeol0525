### 프로젝트 소개

베아트라는 임산부와 예비 부모가 임신·출산 과정을 더 쉽게 이해하고 준비할 수 있도록 만든 메타버스 기반 디지털 헬스케어 플랫폼입니다.

정식 플랫폼 출시 전, 핵심 교육 기능을 검증하기 위해 메타버스 기반 **임신·출산교실 시범 운영**을 진행했습니다. 고려대학교 구로병원을 비롯해 국민건강보험공단 일산병원, 동국대학교일산병원, 경기도의료원 포천병원, 강동경희대학교병원, 용인세브란스병원 등 의료기관과 함께 운영했습니다.

Unity로 로비, 교육장, 상담소, 도서관, 극장, 부스장으로 구성된 3D 가상 공간을 구현했습니다. 사용자는 공간을 이동하며 강연을 시청하고, 질문을 남기거나 의료·건강 자료와 영상 콘텐츠를 확인할 수 있습니다.

시범 운영에서 교육장 기능을 통해 교수의 실시간 화면 공유 강연을 제공했습니다. Unity 클라이언트는 Agora RTC로 원격 화면을 수신해 교육장 화면에 표시하고, Socket.IO 기반 채팅으로 강연자와 참여자 간 실시간 소통을 지원했습니다.

### 담당 업무

- Unity 기반 3D 메타버스 공간 및 공간별 인터랙션 기능 구현
- 로비, 교육장, 상담소, 도서관, 극장, 부스장을 이동하며 콘텐츠를 이용하는 사용자 흐름 구성
- Agora RTC를 활용한 원격 화면 공유 수신 및 교육장 화면 표시 기능 구현
- Socket.IO 기반 실시간 채팅 기능 연동
- 다중 사용자 환경에서 아바타 이동과 좌석 상태를 동기화하는 기능 구현
- 3D 콘텐츠 및 UI 기능 구현, 공통 기능 구조 개선
- Unity Profiler를 활용한 성능 확인 및 개선 작업 참여

### 주요 공간

- **교육장**: 교수의 실시간 화면 공유 강연 시청 및 채팅 참여
- **상담소**: 교수에게 질문을 남기고 답변을 확인하는 공간
- **도서관**: 의료·건강 관련 자료를 열람하는 공간
- **극장**: 임신·출산 관련 영상 콘텐츠를 시청하는 공간
- **부스장**: 참여 기업과 관련 정보를 탐색하는 공간

### 기술적으로 집중한 부분

Agora RTC로 원격 화면 공유를 수신해 3D 공간의 교육장 화면에 표시하고, Socket.IO 기반 채팅을 연결해 참여자가 강연을 보면서 질문과 의견을 나눌 수 있도록 구성했습니다.

- 장비 데이터에 따라 Unity 화면 상태를 갱신하는 기능 구현
- 교육 시뮬레이션을 위한 UI 및 사용자 흐름 구성
- 장비 연동 과정에서 발생하는 연결 상태와 예외 상황 처리
